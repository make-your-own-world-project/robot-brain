# Behalten Sie die Korrektur bei, ohne den Fehler zu löschen

![Frühere Beweise, späteres Verständnis und Veränderungen bleiben im Laufe der Zeit miteinander verbunden.](../../illustrations/temporal-meaning-preserved-history.png)

Veränderungen verstehen. Neue Erkenntnisse können eine frühere Schlussfolgerung korrigieren. Ein späterer Test kann zeigen, dass die erste Erklärung falsch war. Das macht die frühere Aufzeichnung nicht wertlos.

Der Fehler kann erklären, warum eine Entscheidung getroffen wurde, warum Zeit verloren ging oder warum jetzt eine Schutzmaßnahme besteht. Das Umschreiben der alten Notiz würde diese Geschichte verbergen.

## Eine Veranstaltung kann mehrere Termine haben

Das Datum einer Datei ist nicht immer das Datum des darin enthaltenen Ereignisses. Ein nützlicher Datensatz muss möglicherweise unterscheiden:

- wenn etwas passiert ist
- als jemand es aufschrieb
- wann die Datei hier gespeichert wurde
- als eine spätere Interpretation vorgenommen wurde
- wenn eine Schlussfolgerung aktuell wurde oder ersetzt wurde

Wenn eines dieser Daten nicht bekannt ist, bleibt es unbekannt.

## Ein einfaches Beispiel

Eine frühe Notiz gibt einem defekten Teil die Schuld. Ein späterer Test zeigt, dass eine Leistungseinstellung die wahrscheinlichere Ursache war.

Die korrigierte Anamnese sollte die frühe Diagnose, den späteren Test und die neue Schlussfolgerung enthalten. Es sollte zeigen, warum sich die Schlussfolgerung geändert hat. Die erste Notiz sollte nicht so bearbeitet werden, dass es so aussieht, als wüsste jeder die Antwort von Anfang an.

## Warum das neueste Modell nicht das nächste Kapitel ist

Auch Sprachmodelle ändern sich. Ein neues Modell wurde aus einer anderen Mischung aus Quellen, Sprachen, Labels, menschlichem Feedback und Produktregeln erstellt. Es kann insgesamt eine bessere Leistung erbringen, während ein älterer kultureller Bezug, eine lokale Praxis, ein Witz oder eine Minderheitsinterpretation verloren geht.

Die neue Antwort ist keine vollständige Aktualisierung des Wissens des alten Modells. Es ist eine neue Antwort aus einem anderen Modell.

Bei jedem Befund wird aufgezeichnet, welches Modell ihn erzeugt hat, was dem Modell gezeigt wurde und wann es geantwortet hat. Eine neuere Antwort kann hinzugefügt werden, ohne die frühere stillschweigend zu ersetzen.

## Lassen Sie ehrliche Lücken

Manchmal zeigt die Aufzeichnung, dass sich etwas geändert hat, aber nicht warum. In diesem Fall bleibt der Grund offen.

Eine sichtbare Lücke ist nützlicher als eine selbstbewusste Geschichte, die erfunden wurde, um der Zeitleiste das Gefühl zu geben, vollständig zu sein.
