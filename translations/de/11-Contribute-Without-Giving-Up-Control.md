# Helfen Sie ohne die Herausgabe privater Unterlagen

![Menschen können auf begrenzten Wegen einen Beitrag leisten, ohne die Kontrolle über ihre eigene Arbeit abzugeben.](../../illustrations/open-work-collaboration.png)

Jemand kann diesem Projekt helfen, ohne die private Geschichte von irgendjemandem zu sehen oder mit jedem Teil des Entwurfs einverstanden zu sein.

Ein nützlicher Beitrag könnte sein, einen Test zu wiederholen, eine Behauptung in Frage zu stellen, ein kleines Tool zu verbessern, einen fehlenden Standpunkt zu finden oder zu zeigen, dass eine einfachere Methode besser funktioniert.

## Arbeit, die helfen würde

- Wiederholen Sie einen dokumentierten Test mit unabhängig kontrolliertem Material.
- Testen Sie, ob eine benannte Methode eine bessere Leistung als eine einfache Vergleichsmethode erbringt.
- Verbessern Sie die Erhaltung von Quellen, Korrekturen und Beziehungen.
- Finden Sie klarere Möglichkeiten, um zu zeigen, woher ein Anspruch stammt und was ungewiss bleibt.
- Messen Sie, wie viel Zeit Menschen mit dem Lesen und Korrigieren von Ergebnissen verbringen.
- Identifizieren Sie Annahmen im Zusammenhang mit Sprache, Kultur, Behinderung, Beruf oder Studienfach.
- Entdecken Sie Möglichkeiten für separat gesteuerte Installationen, um nur das auszutauschen, was eine Aufgabe benötigt.
- Veröffentlichen Sie einen fehlgeschlagenen Test so deutlich, dass jemand anderes daraus lernen kann.

## Was für ein Beitrag erklären soll

In einem nützlichen Bericht werden die Fragestellung, das verwendete Material, die Erlaubnis zur Verwendung dieses Materials, die Methode, die Bedingungen, das Ergebnis und die bekannten Schwächen aufgeführt.

Es sollte auch angegeben werden, ob es sich bei der Arbeit um eine Idee, einen isolierten Test, einen Test verbundener Teile oder um etwas handelt, das im normalen Gebrauch läuft. Diese Zustände sind nicht austauschbar.

## Was Mitwirkende behalten

Mitwirkende müssen keine privaten Datensätze übertragen, denselben Sprachmodellanbieter verwenden, eine Weltanschauung akzeptieren oder diesem Projekt die Kontrolle über nicht verwandte Arbeiten geben.

Ihr Material kann unter ihrer Kontrolle bleiben. Ein gemeinsames Ergebnis sollte aufzeigen, was, warum und unter welchen Bedingungen ausgetauscht werden darf.

## Nicht einreichen

Senden Sie keine privaten Aufzeichnungen, Passwörter, Zugangsschlüssel, Arbeitgeber- oder Kundeninformationen, private Informationen einer anderen Person, eingeschränktes Material oder alles, dessen Rechte unklar sind.

Jeder zukünftige öffentliche Einreichungsprozess erfordert vor seiner Eröffnung eine eigene Überprüfung der Privatsphäre, Sicherheit und Rechte.
