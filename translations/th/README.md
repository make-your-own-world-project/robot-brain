# เก็บบันทึก. เปลี่ยนโมเดล

![บันทึกของบุคคลจะยังคงอยู่ในที่เดียว ในขณะที่ส่วนการทำงานที่แยกจากกันรองรับงานที่จำกัด](../../illustrations/specialist-assembly-line-vs-giant-chatbot.png)

Robot Brain เป็นซอฟต์แวร์สำหรับการอนุรักษ์ประวัติศาสตร์และความหมายเบื้องหลังการทำงานของมนุษย์มายาวนาน ไม่ใช่โมเดลภาษา แชทบอท หรือบริการที่ส่งต่อทุกคำถามไปยังโมเดล

โมเดลภาษาขนาดใหญ่สามารถค้นคว้า เขียน อธิบาย และช่วยแก้ปัญหาที่ยากได้ บริการแบบชำระเงินที่สร้างขึ้นรอบๆ ยังคงเป็นพื้นที่ทำงานชั่วคราว พวกเขาสามารถย่อบทสนทนายาวๆ สูญเสียคำแนะนำก่อนหน้านี้ แยกข้อสรุปออกจากหลักฐาน และเขียนต่อราวกับว่าประวัติศาสตร์ที่หายไปยังคงอยู่ จากนั้นบุคคลจะใช้เวลามากขึ้นและเสียค่าใช้จ่ายในการสร้างบริบทการใช้งานใหม่ที่ได้รับการจัดหาไว้แล้ว

ซอฟต์แวร์นี้จะเปลี่ยนแปลงคุณค่าที่ยั่งยืน การสนทนา เอกสาร การตัดสินใจ ความพยายามที่ล้มเหลว การแก้ไข และคำถามที่ไม่ได้รับคำตอบของบุคคลนั้นยังคงอยู่ในบันทึกที่บุคคลควบคุม โปรแกรมท้องถิ่นสามารถตรวจสอบบันทึกเหล่านั้นได้ แบบจำลองภาษาสามารถช่วยในงานที่เลือกได้ แต่การสนับสนุนจะส่งคืนไปยังเรกคอร์ดเป็นงานที่ลงวันที่และตรวจทานได้ สามารถเปลี่ยนแบบจำลองได้โดยไม่ต้องนำประวัติไปด้วย

Robot Brain อาจเรียกแบบจำลองภาษาท้องถิ่นหรือออนไลน์ นั่นไม่ได้เปลี่ยนให้เป็นพร็อกซีโมเดล สามารถเก็บรักษา ค้นหา เปรียบเทียบ จัดระเบียบ และสร้างงานก่อนหน้านี้ใหม่ได้โดยไม่ต้องเรียกโมเดลที่มีส่วนร่วมในการสนทนาต้นฉบับ เมื่อโมเดลมีประโยชน์ คำขอจะเป็นขั้นตอนหนึ่งในกระบวนการที่ใหญ่กว่าที่มีอยู่โดยอิสระจากโมเดลนั้น

## ทำไมถึงสร้างสิ่งนี้ขึ้นมา.

โมเดลสำหรับใช้งานทั่วไปที่ได้รับค่าตอบแทนที่แข็งแกร่งที่สุดที่มีอยู่ระหว่างการพัฒนาคือผู้ดูแลการทำงานระยะยาวที่มีความสามารถแต่ไม่น่าเชื่อถือ

ความล้มเหลวที่บันทึกไว้ ได้แก่ คำแนะนำที่สูญหาย หลักฐานที่หายไป การเชื่อมต่อที่ประดิษฐ์ขึ้น การกล่าวอ้างว่าเสร็จสิ้นก่อนเวลาอันควร การเปลี่ยนแปลงที่ไม่พึงประสงค์ และความเสียหายต่อไฟล์งาน การแก้ไขความล้มเหลวเหล่านั้นต้องใช้คำขอมากขึ้น การทดสอบมากขึ้น เงินช่วยเหลือที่จ่ายมากขึ้น และเวลาและพลังงานของบุคคลนั้นมากขึ้น บริการดังกล่าวไม่ได้คืนการใช้งานที่ใช้กับงานที่ไม่ได้ใช้หรือการแลกเปลี่ยนที่จำเป็นในการซ่อมแซมโดยอัตโนมัติ

ปัญหาใหญ่กว่าคำตอบที่ไม่ดีข้อใดข้อหนึ่ง เครื่องมือสร้างข้อความชั่วคราวถูกขอให้ทำหน้าที่เป็นความทรงจำ นักประวัติศาสตร์ นักวิจัย นักเขียน ผู้ตรวจสอบ และผู้ตัดสินขั้นสุดท้าย การเปลี่ยนโมเดลไม่ได้เปลี่ยนการจัดเรียงนั้น

Robot Brain ถูกสร้างขึ้นโดยมีการจัดการที่แตกต่างกัน: เก็บบันทึกของมนุษย์ไว้ก่อน ปล่อยให้ชิ้นส่วนที่เปลี่ยนได้หลายชิ้นมีส่วนช่วย และต้องการหลักฐานภายนอกแบบจำลองการสร้างก่อนที่งานสำคัญจะได้รับการยอมรับ

## สิ่งที่โมเดลที่ผ่านการฝึกอบรมไม่สามารถรักษาไว้ได้

แบบจำลองภาษาขนาดใหญ่เรียนรู้รูปแบบจากคอลเล็กชั่นงานของมนุษย์จำนวนมหาศาล รูปแบบเหล่านั้นทำให้โมเดลมีประโยชน์ แต่โมเดลไม่ใช่คลังของผลงานที่สมบูรณ์ที่สร้างรูปร่างขึ้นมา

ภายในโมเดล อิทธิพลจากหนังสือ บทความ การสนทนา การแปล ชุมชน ป้ายกำกับ และคำติชมของมนุษย์ถูกผสมผสานเข้าด้วยกัน แบบจำลองมักจะไม่สามารถแสดงว่าแหล่งใดสร้างประโยคใดประโยคหนึ่งโดยเฉพาะ ไม่สามารถเรียกคืนวัตถุประสงค์ ผู้ฟัง หลักฐาน ความขัดแย้ง การแก้ไขในภายหลัง หรือมุมมองที่ขาดหายไปของผู้เขียนทุกคนได้

นั่นคือการสูญเสียความหมายแม้ว่างานต้นฉบับยังคงมีอยู่ในที่อื่นก็ตาม แบบจำลองยังคงรักษาประโยชน์บางอย่างจากงาน ในขณะที่ละทิ้งเส้นทางที่เชื่อถือได้กลับไปสู่สภาพแวดล้อมของมนุษย์

ปัญหาเดียวกันนี้เกิดขึ้นระหว่างการใช้งานปกติ คำตอบสุดท้ายอาจยังคงอยู่หลังจากบทสนทนาที่ให้ความหมายสั้นลง ข้อสรุปยังคงอยู่ แต่ความพยายามที่ล้มเหลว ความไม่แน่นอน และเหตุผลที่อยู่เบื้องหลังนั้นหายไปจากมุมมองการทำงานของแบบจำลอง

โปรเจ็กต์นี้ไม่ได้ตอบคำถามนั้นด้วยการฝึกโมเดลอื่นเกี่ยวกับชีวิตของบุคคล ประวัติส่วนตัวยังคงสามารถอ่านและติดตามได้ แทนที่จะนำไปผสมผสานเข้ากับโมเดลที่ผ่านการฝึกอบรมอื่น โมเดลทำงานกับเรกคอร์ดที่เลือก สิ่งเหล่านี้จะไม่กลายเป็นบันทึก

## แต่ละส่วนทำหน้าที่อะไร

ซอฟต์แวร์ที่ใช้งานได้จะแยกงานที่บริการแชทมักจะทำให้ดูเหมือนเป็นกิจกรรมเดียว:

๑. **ผู้รักษาแหล่งที่มาบันทึกสิ่งที่เกิดขึ้น** โดยจะเก็บการสนทนา เอกสาร รูปภาพ หรือเนื้อหาอื่นๆ โดยไม่ต้องแทนที่ด้วยข้อมูลสรุป
๒. **สำเนาที่ค้นหาได้ทำให้ค้นหาแหล่งที่มาได้ง่ายขึ้น** ข้อความ คำอธิบาย และดัชนีที่คัดลอกจะชี้กลับไปยังแหล่งที่มาที่ไม่เปลี่ยนแปลงและสามารถสร้างใหม่ได้
๓. **ผู้อ่านในท้องถิ่นโดยเฉพาะจะตรวจสอบคุณลักษณะเฉพาะ** วิธีการแยกจะพิจารณาภาษา ข้อความ ความสัมพันธ์ การใช้เหตุผล เวลา ประสบการณ์ของมนุษย์ และค่านิยม แต่ละรายงานเฉพาะการค้นพบของตนเองและข้อความเบื้องหลังเท่านั้น
๔. **บันทึกประวัติช่วยให้มองเห็นการเปลี่ยนแปลง** มีการเพิ่มเติมข้อค้นพบใหม่ การแก้ไข ความขัดแย้ง ความพยายามที่ล้มเหลว และคำถามปลายเปิดโดยไม่ต้องเขียนเหตุการณ์ก่อนหน้านี้ใหม่
๕. **ตัวสร้างคำขอรวบรวมสิ่งที่งานหนึ่งต้องการ** โดยจะเลือกแหล่งที่มาและผลการวิจัยที่เกี่ยวข้อง และบันทึกสิ่งที่รวมไว้หรือที่ละทิ้ง
๖. **โมเดลภาษาอาจเพิ่มความช่วยเหลือแบบจำกัด** โมเดลท้องถิ่นสามารถให้พื้นหลังแบบกว้างๆ ได้ โมเดลออนไลน์สามารถช่วยค้นคว้าหรือเขียนเรื่องยากๆ ได้ การตอบกลับอย่างใดอย่างหนึ่งยังคงเป็นการสนับสนุนแบบลงวันที่ที่สามารถตรวจสอบ ปฏิเสธ หรือแทนที่ได้
๗. **แยกเช็คเปรียบเทียบผลกับคำขอและหลักฐาน** โมเดลที่เขียนคำตอบไม่สามารถประกาศผลงานของตัวเองได้
๘. **หน้าจอให้บุคคลใช้ซอฟต์แวร์ได้** รวมมาด้วยLibreChatfork เป็นหนึ่งในหน้าจอดังกล่าว การเปลี่ยนไม่ได้เป็นการแทนที่บันทึกหรือส่วนการทำงานอื่นๆ

ไม่มีการนำเสนอส่วนใดส่วนหนึ่งในฐานะผู้ช่วยผู้รอบรู้ งานที่จำกัดของพวกเขาคือสิ่งที่ทำให้แต่ละชิ้นส่วนสามารถเปลี่ยนได้

## ทำให้การสนทนาที่เสร็จสิ้นแล้วมีประโยชน์อีกครั้ง

การสนทนาที่เสร็จสมบูรณ์ประกอบด้วยคำขอของบุคคล การตอบกลับที่แท้จริงของโมเดลภาษา ความพยายามในการทำงาน ความล้มเหลว การแก้ไข และจุดที่การแลกเปลี่ยนสิ้นสุดลง ข้อความเหล่านั้นจะรักษาสิ่งที่โมเดลดั้งเดิมมีส่วนร่วมโดยไม่ต้องให้โมเดลนั้นอธิบายตัวเองในภายหลัง

ผู้อ่านในท้องถิ่นที่มุ่งเน้นจะตรวจสอบการแลกเปลี่ยนที่บันทึกไว้จากหลายมุม พวกเขาสามารถค้นหารูปแบบและความสัมพันธ์โดยละเอียดโดยไม่ต้องอาศัยความรู้ระดับโลก การค้นพบที่แยกจากกันของพวกเขายังคงเชื่อมโยงกับบทสนทนาบางส่วน

การค้นพบเหล่านั้นอาจยังต้องอาศัยความรู้พื้นฐานทั่วไปก่อนที่จะสร้างบัญชีที่ชัดเจน สำหรับก้าวอันจำกัดนั้น แม้จะเล็กน้อยก็ตามQwenโมเดลทำงานภายในเครื่องvLLM. โดยเพิ่มภาพรวมที่ลงวันที่ซึ่งช่วยเชื่อมโยงการค้นพบโดยละเอียดและอธิบายว่าการแลกเปลี่ยนบรรลุผลสำเร็จอย่างไร

Qwenไม่สามารถกู้คืนความคิดหรือประวัติการฝึกที่ซ่อนอยู่ของโมเดลออนไลน์ได้ โดยให้ความรู้พื้นฐานอย่างกว้างๆ ที่ไม่ซ้ำกับรุ่นดั้งเดิม การสนับสนุนที่เป็นประโยชน์ของโมเดลดั้งเดิมได้รับการเก็บรักษาไว้แล้วในคำพูดที่สร้างขึ้น

ที่Qwenภาพรวมจะถูกเก็บไว้ข้างแหล่งที่มาและการค้นพบก่อนหน้านี้ สามารถแก้ไขได้หรือเปลี่ยนใหม่ บทสนทนาดั้งเดิมและการวิเคราะห์ในท้องถิ่นโดยละเอียดยังคงไม่เปลี่ยนแปลง

## ตอนนี้ทำงานอะไรอยู่

การใช้งานปัจจุบันสามารถรักษาการสนทนาที่เสร็จสมบูรณ์ ตรวจสอบด้วยวิธีการท้องถิ่นที่แยกจากกัน เพิ่มการอ่านความรู้ทั่วไปในท้องถิ่น และรวบรวมการมีส่วนร่วมที่เก็บไว้ทั้งหมดไว้ในบันทึกที่สามารถสร้างใหม่ได้ในภายหลัง

นอกจากนี้ยังสามารถจัดเตรียมคำขอแบบจำกัดสำหรับโมเดลออนไลน์ได้เมื่อความช่วยเหลือจากภายนอกมีประโยชน์ บริการนั้นจะได้รับเฉพาะวัสดุที่เลือกเท่านั้น คำตอบจะกลับไปยังบันทึกในท้องที่ โดยที่การตรวจสอบและการอนุมัติจากมนุษย์ (ไม่ใช่แบบจำลอง) จะเป็นผู้ตัดสินใจว่าอะไรจะถูกเก็บไว้

นี่คือความสำเร็จหลัก: งานที่ครั้งหนึ่งเคยขึ้นอยู่กับการสนทนาชั่วคราวครั้งหนึ่งจะยังคงมีประโยชน์ต่อไปหลังจากที่หน้าจอแชท โมเดล และผู้ให้บริการหายไป

## ความเป็นอิสระและความเป็นส่วนตัว

นี่เป็นโปรเจ็กต์ส่วนบุคคลอิสระที่พัฒนาขึ้นโดยอิงเวลาส่วนตัว อุปกรณ์ บัญชี และบริการแบบชำระเงิน ไม่มีนายจ้างเข้าร่วมด้วย การกล่าวถึงบุคคล นายจ้าง สถาบัน ผู้ให้บริการต้นแบบ กลุ่มวิจัย กฎที่ใช้ร่วมกัน หรือโครงการภายนอกไม่ได้หมายความถึงการมีส่วนร่วม การอนุมัติ ความร่วมมือ หรือการรับรอง

การเผยแพร่สู่สาธารณะไม่รวมบันทึกส่วนตัว รายละเอียดการระบุ รหัสผ่าน ข้อมูลการเชื่อมต่อส่วนตัว ข้อมูลนายจ้าง และคำแนะนำในการเข้าถึงบริการส่วนตัว คำอธิบายของความล้มเหลวของโมเดลนั้นจำกัดอยู่เพียงพฤติกรรมที่บันทึกไว้และผลกระทบของมัน พวกเขาไม่ได้อ้างสาเหตุหรือแรงจูงใจที่ไม่เปิดเผย เอกสารดังกล่าวไม่ใช่คำแนะนำจากผู้เชี่ยวชาญหรือคำมั่นสัญญาถึงผลลัพธ์
