# Βοηθήστε χωρίς να παραδώσετε προσωπικά αρχεία

![Οι άνθρωποι μπορούν να συνεισφέρουν μέσα από περιορισμένα μονοπάτια χωρίς να παραδώσουν τον έλεγχο της δουλειάς τους.](../../illustrations/open-work-collaboration.png)

Κάποιος μπορεί να βοηθήσει αυτό το έργο χωρίς να δει το ιδιωτικό ιστορικό κανενός ή να συμφωνήσει με κάθε μέρος του σχεδιασμού.

Μια χρήσιμη συνεισφορά μπορεί να επαναλάβει μια δοκιμή, να αμφισβητήσει μια αξίωση, να βελτιώσει ένα μικρό εργαλείο, να βρει μια άποψη που λείπει ή να δείξει ότι μια απλούστερη μέθοδος λειτουργεί καλύτερα.

## Δουλειά που θα βοηθούσε

- Επαναλάβετε μια τεκμηριωμένη δοκιμή με ανεξάρτητα ελεγχόμενο υλικό.
- Ελέγξτε εάν μια μέθοδος με όνομα έχει καλύτερη απόδοση από μια απλή μέθοδο σύγκρισης.
- Βελτιώστε τον τρόπο με τον οποίο διατηρούνται οι πηγές, οι διορθώσεις και οι σχέσεις.
- Βρείτε πιο ξεκάθαρους τρόπους για να δείξετε από πού προήλθε μια αξίωση και τι παραμένει αβέβαιο.
- Μετρήστε πόσο χρόνο αφιερώνουν οι άνθρωποι διαβάζοντας και διορθώνοντας τα αποτελέσματα.
- Προσδιορίστε υποθέσεις που συνδέονται με τη γλώσσα, τον πολιτισμό, την αναπηρία, το επάγγελμα ή τον τομέα σπουδών.
- Εξερευνήστε τρόπους για χωριστά ελεγχόμενες εγκαταστάσεις να ανταλλάσσουν μόνο αυτά που χρειάζεται μια εργασία.
- Δημοσιεύστε ένα αποτυχημένο τεστ αρκετά ξεκάθαρα ώστε κάποιος άλλος να μπορεί να μάθει από αυτό.

## Τι πρέπει να εξηγήσει μια συνεισφορά

Μια χρήσιμη αναφορά αναφέρει την ερώτηση, το υλικό που χρησιμοποιήθηκε, την άδεια χρήσης αυτού του υλικού, τη μέθοδο, τις συνθήκες, το αποτέλεσμα και τις γνωστές αδυναμίες.

Θα πρέπει επίσης να λέει εάν το έργο είναι μια ιδέα, μια μεμονωμένη δοκιμή, μια δοκιμή συνδεδεμένων εξαρτημάτων ή κάτι που λειτουργεί σε συνηθισμένη χρήση. Αυτά τα κράτη δεν είναι εναλλάξιμα.

## Τι κρατούν οι συντελεστές

Οι συνεισφέροντες δεν χρειάζεται να μεταφέρουν ιδιωτικά αρχεία, να χρησιμοποιούν τον ίδιο πάροχο μοντέλου γλώσσας, να αποδέχονται μια κοσμοθεωρία ή να δίνουν σε αυτό το έργο τον έλεγχο άσχετων εργασιών.

Το υλικό τους μπορεί να παραμείνει υπό τον έλεγχό τους. Ένα κοινό αποτέλεσμα θα πρέπει να προσδιορίζει τι μπορεί να ανταλλάσσεται, γιατί και με ποιους όρους.

## Μην υποβάλετε

Μην στέλνετε ιδιωτικά αρχεία, κωδικούς πρόσβασης, κλειδιά πρόσβασης, πληροφορίες εργοδότη ή πελάτη, ιδιωτικές πληροφορίες άλλου ατόμου, περιορισμένο υλικό ή οτιδήποτε του οποίου τα δικαιώματα είναι ασαφή.

Οποιαδήποτε μελλοντική διαδικασία δημόσιας υποβολής θα χρειαστεί τον δικό της έλεγχο απορρήτου, ασφάλειας και δικαιωμάτων προτού ανοίξει.
