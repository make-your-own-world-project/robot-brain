# Τι ακολουθεί

Το τρέχον λογισμικό καταδεικνύει ήδη την κεντρική ιδέα: ένα μοντέλο επί πληρωμή γλώσσας μπορεί να βοηθήσει σε μια εργασία χωρίς να γίνει η μόνιμη κατοικία των αρχείων του ατόμου.

Το επόμενο έργο δεν είναι ένα μεγαλύτερο συγκεντρωτικό μοντέλο ή ένα τοπικό μοντέλο εκπαιδευμένο στη ζωή κάποιου. Είναι καλύτερος έλεγχος, σαφέστερη χρήση και ασφαλέστερη ανταλλαγή μεταξύ εγγραφών που παραμένουν υπό τον έλεγχο διαφορετικών ανθρώπων.

## Ανεξάρτητη δοκιμή

Το πιο δυνατό επόμενο βήμα είναι μια ανεξάρτητη ομάδα να δοκιμάσει την ίδια σχεδίαση με διαφορετικές εγγραφές, άτομα, εργαλεία και υπηρεσίες μοντέλων γλώσσας.

Αυτή η εργασία πρέπει να προστατεύει τις προσωπικές πληροφορίες και να αποφεύγει την αντιγραφή προσωπικών στοιχείων από την τρέχουσα εγκατάσταση.

## Πιο ισχυρά στοιχεία για σχέσεις

Απαιτούνται περισσότερες δοκιμές για συνδέσμους μεταξύ γεγονότων, διορθώσεων, ταυτοτήτων με την πάροδο του χρόνου και του νοήματος που αποδίδεται σε μια πηγή.

Οι μελλοντικοί έλεγχοι σχέσεων πρέπει να διακρίνουν μια υποστηριζόμενη σύνδεση από μια που ακούγεται απλώς πιθανή. Όταν δεν μπορεί να προσδιοριστεί μια ημερομηνία, ταυτότητα ή αιτία, το αρχείο που διατηρείται θα πρέπει να αφήνει ανοιχτή την ερώτηση.

Το ορόσημο της ολοκληρωμένης συνομιλίας έφερε κάθε συνεισφορά που διατηρήθηκε για μία ανταλλαγή σε ένα αρχείο που μπορεί να ξαναδημιουργηθεί. Οι μελλοντικές δοκιμές θα εφαρμόσουν την ίδια μέθοδο σε περισσότερες συνομιλίες, αντικρουόμενους λογαριασμούς, μεταγενέστερες διορθώσεις και άλλα είδη υλικού.

## Σαφέστεροι τρόποι επιθεώρησης του αρχείου

Οι άνθρωποι πρέπει να βλέπουν πηγές, ευρήματα, διορθώσεις, παραλείψεις, κόστος και έγκριση χωρίς να διαβάζουν εσωτερικά αρχεία προγράμματος.

Οι οθόνες πρέπει να οδηγούν με το χρήσιμο αποτέλεσμα, να δείχνουν από πού προήλθε και να εξηγούν προβλήματα στη συνηθισμένη γλώσσα.

## Περισσότερες γλώσσες και πολιτισμοί

Οι μελλοντικές εργασίες θα δοκιμάσουν αρχεία από περισσότερες γλώσσες, πολιτισμούς, μέρη και μορφές γνώσης.

Η μετάφραση πρέπει να διατηρεί από πού προήλθε μια ιδέα και να προσδιορίζει ιδέες που δεν ταιριάζουν απόλυτα στις συνήθεις λέξεις του έργου. Οι άπταιστα ομιλητές και οι σχετικές κοινότητες χρειάζονται έναν τρόπο να διορθώσουν μια ερμηνεία χωρίς να εγκαταλείψουν τον έλεγχο της δικής τους γνώσης.

Όταν ένας πάροχος δεν αποκαλύπτει τι διαμόρφωσε ένα μοντέλο, οι πληροφορίες που λείπουν θα πρέπει να παραμένουν άγνωστες. Δεν πρέπει να αντιμετωπίζεται ως πολιτισμικά ουδέτερο ή ιστορικά ολοκληρωμένο.

## Ανταλλαγή χωρίς παράδοση

Οι εγκαταστάσεις που ελέγχονται από διαφορετικά άτομα ή ομάδες θα πρέπει να μπορούν να ανταλλάσσουν εγκεκριμένη εργασία χωρίς να μεταφέρουν όλα τα προσωπικά τους αρχεία.

Μια ανταλλαγή πρέπει να διατηρεί την πηγή, τον σκοπό, την επιτρεπόμενη χρήση, την αβεβαιότητα, τις διορθώσεις και το ποιος παρείχε το υλικό. Καμία πλευρά δεν πρέπει να αποκτήσει κρυφή δύναμη για να αποφασίσει τι σημαίνουν τα αρχεία της άλλης πλευράς.

## Τίμιες καταγραφές κόστους

Η επιλογή εργαλείου θα πρέπει να περιλαμβάνει τα τέλη εξυπηρέτησης, τα όρια χρήσης, την ενέργεια, την αναμονή, τις επαναλήψεις, τη συντήρηση και τον χρόνο που αφιερώνουν οι άνθρωποι για την εύρεση και τη διόρθωση λαθών.

Ένα ισχυρό διαδικτυακό μοντέλο μπορεί να εξακολουθεί να είναι το σωστό εργαλείο. Το αρχείο θα πρέπει να καθιστά σαφές γιατί το αποτέλεσμα δικαιολογούσε το πλήρες κόστος του.

## Δημόσια τεκμηρίωση

Οι μελλοντικές εκδόσεις θα συνεχίσουν να λαμβάνουν ξεχωριστούς ελέγχους για αναγνώσιμη γλώσσα, πηγές, δικαιώματα, απόρρητο, πληροφορίες απασχόλησης, εικονογραφήσεις και μεταφράσεις.

Κάθε δημόσια αξίωση θα προσδιορίζει τα αποδεικτικά στοιχεία πίσω από αυτήν. Κάθε έκδοση θα ονομάζει τα ακριβή αρχεία και τον προορισμό που έχουν εγκριθεί για δημοσίευση.

Ο στόχος είναι να μην σταματήσουμε να χρησιμοποιούμε εμπορικά γλωσσικά μοντέλα. Είναι να σταματήσεις να βασίζεσαι σε κάποιο από αυτά για να διατηρήσεις την ιστορία ενός ατόμου.
