# Κρατήστε το αρχείο. Αντικαταστήστε το μοντέλο.

![Τα αρχεία ενός ατόμου παραμένουν σε ένα μέρος, ενώ τα ξεχωριστά μέρη εργασίας χειρίζονται περιορισμένες εργασίες.](../../illustrations/specialist-assembly-line-vs-giant-chatbot.png)

Robot Brain είναι λογισμικό για τη διατήρηση της ιστορίας και του νοήματος πίσω από τη μακροχρόνια ανθρώπινη εργασία. Δεν είναι ένα μοντέλο γλώσσας, ένα chatbot ή μια υπηρεσία που προωθεί κάθε ερώτηση σε ένα μοντέλο.

Τα μεγάλα γλωσσικά μοντέλα μπορούν να ερευνήσουν, να γράψουν, να εξηγήσουν και να βοηθήσουν στην επίλυση δύσκολων προβλημάτων. Οι επί πληρωμή υπηρεσίες που δημιουργούνται γύρω τους εξακολουθούν να είναι προσωρινοί χώροι εργασίας. Μπορούν να συντομεύσουν μια μακρά συζήτηση, να χάσουν προηγούμενες οδηγίες, να διαχωρίσουν τα συμπεράσματα από τα στοιχεία τους και να συνεχίσουν να γράφουν σαν να ήταν ακόμα παρούσα η ιστορία που λείπει. Στη συνέχεια, ένα άτομο ξοδεύει περισσότερο χρόνο και πληρωμένη χρήση για την αναδόμηση του περιβάλλοντος που είχε ήδη παρασχεθεί.

Αυτό το λογισμικό αλλάζει εκεί που ζει η διαρκής αξία. Οι συνομιλίες, τα έγγραφα, οι αποφάσεις, οι αποτυχημένες προσπάθειες, οι διορθώσεις και οι αναπάντητα ερωτήσεις του ατόμου παραμένουν στα αρχεία που ελέγχει το άτομο. Τα τοπικά προγράμματα μπορούν να εξετάσουν αυτές τις εγγραφές. Ένα μοντέλο γλώσσας μπορεί να βοηθήσει με μια επιλεγμένη εργασία, αλλά η συνεισφορά του επιστρέφει στο αρχείο ως χρονολογημένη εργασία με δυνατότητα αξιολόγησης. Το μοντέλο μπορεί στη συνέχεια να αντικατασταθεί χωρίς να πάρει μαζί του το ιστορικό.

[Διαβάστε αυτήν την τεκμηρίωση σε άλλη γλώσσα.](../README.md)

## Η διαφορά σε μια άποψη

| Μια εμπορική υπηρεσία γλωσσικού μοντέλου | Robot Brain |
|---|---|
| Παράγει μια απάντηση από το υλικό που βρίσκεται αυτή τη στιγμή στην προβολή εργασίας του. | Διατηρεί την πλήρη πηγή και το ιστορικό γύρω από αυτήν. |
| Μπορεί να συντομεύσει ή να χάσει την προηγούμενη συνομιλία καθώς μεγαλώνει η εργασία. | Αποθηκεύει συνομιλίες εκτός κάθε μοντέλου, ώστε να μπορούν να χρησιμοποιηθούν ξανά. |
| Συνδυάζει τη γνώση που αποκτήθηκε από πολλές πηγές χωρίς μια πλήρη διαδρομή πίσω σε κάθε πηγή και τις περιστάσεις της. | Διατηρεί κάθε γνωστή πηγή, μεταγενέστερη εύρεση, διόρθωση και διαφωνία ως ξεχωριστό αρχείο. |
| Μπορεί να γράψει, να αναζητήσει, να σχεδιάσει και να κρίνει τη δική του απάντηση σε μία ανταλλαγή. | Παρέχει αποθήκευση, αναζήτηση, ανάλυση, εγγραφή, έλεγχο και έγκριση σε ξεχωριστά μέρη με περιορισμένη εξουσία. |
| Ελέγχει το μοντέλο, τους κανόνες υπηρεσίας, τα όρια χρήσης και τις αλλαγές προϊόντων. | Αφήνει το διαρκές αρχείο υπό τον έλεγχο του ατόμου. |
| Πληρώνεται για αποτυχημένες προσπάθειες και διορθωτικές ανταλλαγές καθώς και χρήσιμη εργασία. | Διατηρεί αστοχίες και διορθώσεις, ώστε τα μαθήματά τους να μην χρειάζεται να αγοραστούν ξανά. |

Robot Brain μπορεί να καλέσει ένα τοπικό ή διαδικτυακό μοντέλο γλώσσας. Αυτό δεν το μετατρέπει σε μοντέλο μεσολάβησης. Μπορεί να διατηρήσει, να αναζητήσει, να συγκρίνει, να οργανώσει και να ξαναχτίσει προηγούμενες εργασίες χωρίς να καλέσει το μοντέλο που συμμετείχε στην αρχική συνομιλία. Όταν ένα μοντέλο είναι χρήσιμο, το αίτημα είναι ένα βήμα σε μια ευρύτερη διαδικασία που υπάρχει ανεξάρτητα από αυτό το μοντέλο.

## Γιατί χτίστηκε αυτό

Τα ισχυρότερα αμειβόμενα μοντέλα γενικής χρήσης που ήταν διαθέσιμα κατά την ανάπτυξη ήταν ικανοί αλλά αναξιόπιστοι θεματοφύλακες μακράς εργασίας.

Οι καταγεγραμμένες αποτυχίες περιλάμβαναν χαμένες οδηγίες, ελλείποντα στοιχεία, εφευρεμένες συνδέσεις, πρόωρες αξιώσεις ολοκλήρωσης, ανεπιθύμητες αλλαγές και ζημιές σε αρχεία εργασίας. Η διόρθωση αυτών των αποτυχιών χρειάστηκε περισσότερα αιτήματα, περισσότερες δοκιμές, περισσότερο αμειβόμενο επίδομα και περισσότερο χρόνο και ενέργεια του ατόμου. Οι υπηρεσίες δεν επέστρεψαν αυτόματα τη χρήση που δαπανήθηκε για αχρησιμοποίητη εργασία ή τις ανταλλαγές που απαιτούνται για την επισκευή της.

Το πρόβλημα ήταν μεγαλύτερο από οποιαδήποτε κακή απάντηση. Ζητήθηκε από μια προσωρινή δημιουργία κειμένου να λειτουργήσει ως μνήμη, ιστορικός, ερευνητής, συγγραφέας, ελεγκτής και τελικός κριτής. Η αλλαγή των μοντέλων δεν άλλαξε αυτή τη διάταξη.

Robot Brain χτίστηκε γύρω από μια διαφορετική διάταξη: κρατήστε πρώτα το ανθρώπινο αρχείο, αφήστε πολλά ανταλλακτικά να συνεισφέρουν σε αυτό και απαιτήστε στοιχεία εκτός του μοντέλου παραγωγής πριν γίνει αποδεκτή σημαντική εργασία.

## Αυτό που δεν μπορεί να κρατήσει ένα εκπαιδευμένο μοντέλο

Ένα μεγάλο γλωσσικό μοντέλο μαθαίνει μοτίβα από τεράστιες συλλογές ανθρώπινης εργασίας. Αυτά τα μοτίβα κάνουν το μοντέλο χρήσιμο, αλλά το μοντέλο δεν είναι μια βιβλιοθήκη με τα πλήρη έργα που το διαμόρφωσαν.

Μέσα στο μοντέλο, η επιρροή από βιβλία, άρθρα, συνομιλίες, μεταφράσεις, κοινότητες, ετικέτες και ανθρώπινη ανατροφοδότηση συνδυάζεται. Το μοντέλο συνήθως δεν μπορεί να δείξει ποιες πηγές διαμόρφωσαν μια συγκεκριμένη πρόταση. Δεν μπορεί να αποκαταστήσει τον σκοπό, το κοινό, τα στοιχεία, τη διαφωνία, τη μεταγενέστερη διόρθωση ή την άποψη που λείπει κάθε συγγραφέα.

Αυτό είναι απώλεια νοήματος, ακόμη και όταν το πρωτότυπο έργο εξακολουθεί να υπάρχει αλλού. Το μοντέλο διατηρεί κάποια χρησιμότητα από την εργασία, ενώ απορρίπτει την αξιόπιστη διαδρομή πίσω στο ανθρώπινο περιβάλλον του.

Το ίδιο πρόβλημα εμφανίζεται κατά τη συνήθη χρήση. Μια τελική απάντηση μπορεί να επιβιώσει μετά τη συντόμευση της συνομιλίας που της έδωσε νόημα. Το συμπέρασμα παραμένει, αλλά οι αποτυχημένες προσπάθειες, η αβεβαιότητα και οι λόγοι πίσω από αυτό εξαφανίζονται από τη λειτουργική άποψη του μοντέλου.

Αυτό το έργο δεν απαντά σε αυτό το πρόβλημα εκπαιδεύοντας ένα άλλο μοντέλο στη ζωή ενός ατόμου. Το προσωπικό ιστορικό παραμένει αναγνώσιμο και ανιχνεύσιμο αντί να αναμιγνύεται σε ένα άλλο εκπαιδευμένο μοντέλο. Τα μοντέλα λειτουργούν με επιλεγμένες εγγραφές. δεν γίνονται οι δίσκοι.

## Τι κάνει το κάθε μέρος

Το λειτουργικό λογισμικό διαχωρίζει εργασίες που μια υπηρεσία συνομιλίας συχνά κάνει να μοιάζουν με μία δραστηριότητα:

1. **Ο φύλακας πηγής αποθηκεύει αυτό που συνέβη.** Διατηρεί τη συνομιλία, το έγγραφο, την εικόνα ή άλλο υλικό χωρίς να το αντικαθιστά με περίληψη.
2. **Τα αντίγραφα με δυνατότητα αναζήτησης διευκολύνουν την εύρεση της πηγής.** Το αντιγραμμένο κείμενο, οι περιγραφές και τα ευρετήρια οδηγούν στην αμετάβλητη πηγή και μπορούν να αναδημιουργηθούν.
3. **Εστιασμένοι τοπικοί αναγνώστες εξετάζουν συγκεκριμένα χαρακτηριστικά.** Ξεχωριστές μέθοδοι εξετάζουν τη γλώσσα, τις δηλώσεις, τις σχέσεις, τη λογική, τον χρόνο, την ανθρώπινη εμπειρία και τις αξίες. Το καθένα αναφέρει μόνο τα δικά του ευρήματα και τα αποσπάσματα πίσω από αυτά.
4. **Το αρχείο ιστορικού διατηρεί ορατές τις αλλαγές.** Προστίθενται νέα ευρήματα, διορθώσεις, διαφωνίες, αποτυχημένες προσπάθειες και ανοιχτές ερωτήσεις χωρίς να ξαναγραφούν προηγούμενα συμβάντα.
5. **Το πρόγραμμα δημιουργίας αιτημάτων συγκεντρώνει ό,τι χρειάζεται μια εργασία.** Επιλέγει σχετικές πηγές και ευρήματα και καταγράφει ό,τι συμπεριλήφθηκε ή έμεινε έξω.
6. **Ένα μοντέλο γλώσσας μπορεί να προσθέσει περιορισμένη βοήθεια.** Ένα τοπικό μοντέλο μπορεί να παρέχει ευρύ υπόβαθρο. Ένα διαδικτυακό μοντέλο μπορεί να βοηθήσει με δύσκολη έρευνα ή συγγραφή. Οποιαδήποτε απάντηση παραμένει μια συνεισφορά με ημερομηνία που μπορεί να ελεγχθεί, να απορριφθεί ή να αντικατασταθεί.
7. **Χωριστοί έλεγχοι συγκρίνουν το αποτέλεσμα με το αίτημα και τα αποδεικτικά στοιχεία.** Το μοντέλο που έγραψε μια απάντηση δεν μπορεί να δηλώσει τη δική του εργασία αποδεκτή.
8. **Μια οθόνη επιτρέπει σε ένα άτομο να χρησιμοποιεί το λογισμικό.** ΠεριλαμβάνεταιLibreChatΤο πιρούνι είναι μια τέτοια οθόνη. Η αντικατάστασή του δεν αντικαθιστά τις εγγραφές ή τα άλλα εξαρτήματα εργασίας.

Κανένα τμήμα δεν παρουσιάζεται ως βοηθός που ξέρει τα πάντα. Οι περιορισμένες δουλειές τους είναι αυτές που κάνουν κάθε εξάρτημα αντικαταστάσιμο.

## Κάνοντας μια ολοκληρωμένη συνομιλία χρήσιμη ξανά

Μια ολοκληρωμένη συνομιλία περιέχει το αίτημα του ατόμου, τις πραγματικές απαντήσεις του γλωσσικού μοντέλου, την εργασία που επιχειρήθηκε, τις αποτυχίες, τις διορθώσεις και το σημείο όπου έληξε η ανταλλαγή. Αυτά τα μηνύματα διατηρούν ό,τι συνέβαλε το αρχικό μοντέλο χωρίς να απαιτείται από αυτό το μοντέλο να εξηγηθεί αργότερα.

Οι εστιασμένοι τοπικοί αναγνώστες εξετάζουν τη σωζόμενη ανταλλαγή από διάφορες οπτικές γωνίες. Μπορούν να βρουν λεπτομερή πρότυπα και σχέσεις χωρίς να βασίζονται σε ευρεία παγκόσμια γνώση. Τα χωριστά ευρήματά τους παραμένουν συνδεδεμένα με ακριβή σημεία της συνομιλίας.

Αυτά τα ευρήματα μπορεί να χρειάζονται ακόμα συνήθη γνώση του ιστορικού προτού σχηματίσουν έναν σαφή απολογισμό. Για αυτό το περιορισμένο βήμα, ένα μικρόQwenτο μοντέλο εκτελείται τοπικάvLLM. Προσθέτει μια χρονολογημένη επισκόπηση που βοηθά στη σύνδεση των λεπτομερών ευρημάτων και εξηγεί τι πέτυχε η ανταλλαγή.

Qwenδεν ανακτά τις κρυφές σκέψεις ή το ιστορικό εκπαίδευσης του online μοντέλου. Παρέχει ευρεία βασική γνώση που δεν είναι μοναδική για το αρχικό μοντέλο. Η χρήσιμη συνεισφορά του αρχικού μοντέλου διατηρείται ήδη στις λέξεις που παρήγαγε.

ΟQwenΗ επισκόπηση αποθηκεύεται δίπλα στην πηγή και τα προηγούμενα ευρήματα. Μπορεί να διορθωθεί ή να αντικατασταθεί. Η αρχική συζήτηση και η λεπτομερής τοπική ανάλυση παραμένουν αμετάβλητες.

## Τι λειτουργεί τώρα

Η τρέχουσα υλοποίηση μπορεί να διατηρήσει μια ολοκληρωμένη συνομιλία, να την εξετάσει με ξεχωριστές τοπικές μεθόδους, να προσθέσει μια τοπική ανάγνωση γενικών γνώσεων και να συγκεντρώσει κάθε συνεισφορά που διατηρείται σε μια εγγραφή που μπορεί να ξαναδημιουργηθεί αργότερα.

Μπορεί επίσης να προετοιμάσει ένα περιορισμένο αίτημα για ένα διαδικτυακό μοντέλο όταν είναι χρήσιμη η εξωτερική βοήθεια. Αυτή η υπηρεσία λαμβάνει μόνο το επιλεγμένο υλικό. Η απάντησή του επιστρέφει στο τοπικό αρχείο, όπου οι έλεγχοι και η ανθρώπινη έγκριση -όχι το μοντέλο- αποφασίζουν τι θα κρατηθεί.

Αυτό είναι το κεντρικό επίτευγμα: η εργασία που κάποτε εξαρτιόταν από μια προσωρινή συνομιλία μπορεί να παραμείνει χρήσιμη αφού φύγει η οθόνη συνομιλίας, το μοντέλο και ο πάροχος.

## Ανεξαρτησία και ιδιωτικότητα

Αυτό είναι ένα ανεξάρτητο προσωπικό έργο που αναπτύχθηκε σε προσωπικό χρόνο, εξοπλισμό, λογαριασμούς και υπηρεσίες επί πληρωμή. Κανένας εργοδότης δεν συμμετείχε σε αυτό. Η αναφορά οποιουδήποτε ατόμου, εργοδότη, ιδρύματος, παρόχου μοντέλου, ερευνητικής ομάδας, κοινού κανόνα ή εξωτερικού έργου δεν συνεπάγεται συμμετοχή, έγκριση, συνεργασία ή έγκριση.

Η δημόσια έκδοση εξαιρεί ιδιωτικά αρχεία, στοιχεία αναγνώρισης, κωδικούς πρόσβασης, πληροφορίες ιδιωτικής σύνδεσης, πληροφορίες εργοδότη και οδηγίες πρόσβασης σε ιδιωτικές υπηρεσίες. Οι περιγραφές αστοχιών μοντέλου περιορίζονται στην καταγεγραμμένη συμπεριφορά και τις επιπτώσεις της. δεν ισχυρίζονται άγνωστα αίτια ή κίνητρα. Τα έγγραφα δεν είναι επαγγελματικές συμβουλές ή υπόσχεση αποτελεσμάτων.
