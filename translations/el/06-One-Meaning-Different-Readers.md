# Εξηγήστε την ίδια αλήθεια σε διαφορετικούς αναγνώστες

![Το ίδιο υποστηριζόμενο νόημα μπορεί να εξηγηθεί με μορφές κατάλληλες για διαφορετικούς αναγνώστες.](../../illustrations/human-protocol-weave.png)

Μια δήλωση μπορεί να είναι ακριβής και να είναι άχρηστη για το άτομο που τη διαβάζει. Η απάντηση μπορεί να φτάσει πολύ αργά, να χρησιμοποιήσει άγνωστη γλώσσα ή να θάψει ένα χρήσιμο γεγονός κάτω από σελίδες επεξήγησης.

Αυτή η εργασία χωρίζει δύο αποφάσεις:

1. Τι υποστηρίζουν τα στοιχεία;
2. Ποιος είναι ο πιο ξεκάθαρος τρόπος να το εξηγήσεις σε αυτόν τον αναγνώστη;

Η αλλαγή της εξήγησης δεν πρέπει να αλλάξει τα στοιχεία.

## Ρωτήστε αντί να μαντέψετε

Για μια συγκεκριμένη ανταλλαγή, ο αναγνώστης μπορεί να επιλέξει μια σύντομη απάντηση, μια λεπτομερή εξήγηση, κείμενο, ήχο ή άλλη διαθέσιμη φόρμα. Μπορούν να ζητήσουν περισσότερες λεπτομέρειες, να διορθώσουν μια παρεξήγηση ή να σταματήσουν.

Αυτή η επιλογή ισχύει για την ανταλλαγή. Δεν είναι άδεια να δημιουργήσετε ένα μόνιμο προφίλ προσωπικότητας ή να μαντέψετε την ιδιωτική ψυχική κατάσταση κάποιου.

## Η παρουσίαση δεν είναι αλήθεια

Μόλις οι υποστηριζόμενες αξιώσεις είναι σαφείς, η γραφή μπορεί να αλλάξει τη σειρά, τα παραδείγματα, το επίπεδο λεπτομέρειας και την επεξήγηση των άγνωστων όρων.

Δεν μπορεί να μετατρέψει μια πιθανή ερμηνεία σε γεγονός. Δεν μπορεί να αφαιρέσει μια αποτυχία που χρειάζεται ο αναγνώστης για να κατανοήσει το αποτέλεσμα. Δεν μπορεί να προσθέσει αυτοπεποίθηση για να ακούγεται χρήσιμο.

## Ο χρόνος ανάγνωσης είναι πραγματικό κόστος

Οι πληρωμένοι βοηθοί που χρησιμοποιήθηκαν κατά την ανάπτυξη συχνά παρήγαγαν πολύ περισσότερο κείμενο από αυτό που ζητήθηκε. Επανέλαβαν σημεία, διεύρυναν σύντομες δηλώσεις και τόνισαν σχεδόν τα πάντα. Στη συνέχεια, το άτομο έπρεπε να αναζητήσει την απάντηση, να τη διορθώσει και να εξηγήσει ξανά το αίτημα.

Αυτός ο χρόνος είναι τόσο σημαντικός όσο και τα τέλη εξυπηρέτησης και ο χρόνος υπολογισμού. Περισσότερες λέξεις δεν είναι πιο χρήσιμες όταν κάνουν την απάντηση πιο δύσκολη.

Η καλή ανταπόκριση οδηγεί στο χρήσιμο αποτέλεσμα. Δίνει την εξήγηση που απαιτείται για την κατανόηση και τη χρήση αυτού του αποτελέσματος. Επιπλέον βάθος παραμένει διαθέσιμο όταν το ζητήσει ο αναγνώστης.

## Τι χρειάζεται ακόμα δοκιμή

Το τρέχον λογισμικό μπορεί να ορίσει απαιτήσεις για το μήκος, τα στοιχεία και την ολοκληρωμένη φόρμα. Τα μελλοντικά τεστ πρέπει να συγκρίνουν πόσο καλά επιβιώνει το ίδιο υποστηριζόμενο νόημα σε διαφορετικούς αναγνώστες, γλώσσες, πολιτισμούς και ανάγκες προσβασιμότητας.

Τα άτομα που λαμβάνουν μια εξήγηση πρέπει να είναι σε θέση να τη διορθώσουν. Η διόρθωσή τους γίνεται μέρος του αρχείου και όχι μια κρυφή προτίμηση που μαντεύει ένα μοντέλο.
