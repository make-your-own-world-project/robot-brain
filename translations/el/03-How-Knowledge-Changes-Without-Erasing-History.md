# Κρατήστε τη διόρθωση χωρίς να σβήσετε το λάθος

![Προηγούμενα στοιχεία, μεταγενέστερη κατανόηση και αλλαγές παραμένουν συνδεδεμένα με την πάροδο του χρόνου.](../../illustrations/temporal-meaning-preserved-history.png)

Κατανόηση αλλαγών. Νέα στοιχεία μπορούν να διορθώσουν ένα προηγούμενο συμπέρασμα. Μια μεταγενέστερη δοκιμή μπορεί να δείξει ότι η πρώτη εξήγηση ήταν λάθος. Αυτό δεν καθιστά τον προηγούμενο δίσκο άχρηστο.

Το λάθος μπορεί να εξηγεί γιατί ελήφθη μια απόφαση, γιατί χάθηκε χρόνος ή γιατί υπάρχει τώρα μια διασφάλιση. Η επανεγγραφή της παλιάς σημείωσης θα έκρυβε αυτή την ιστορία.

## Ένα συμβάν μπορεί να έχει πολλές ημερομηνίες

Η ημερομηνία σε ένα αρχείο δεν είναι πάντα η ημερομηνία του συμβάντος μέσα σε αυτό. Ένα χρήσιμο αρχείο μπορεί να χρειαστεί να διακρίνει:

- όταν κάτι συνέβη
- όταν κάποιος το έγραψε
- όταν το αρχείο αποθηκεύτηκε εδώ
- όταν έγινε μεταγενέστερη ερμηνεία
- όταν ένα συμπέρασμα έγινε επίκαιρο ή αντικαταστάθηκε

Εάν μία από αυτές τις ημερομηνίες δεν είναι γνωστή, παραμένει άγνωστη.

## Ένα απλό παράδειγμα

Μια πρώιμη νότα κατηγορεί ένα σπασμένο μέρος. Μια μεταγενέστερη δοκιμή δείχνει ότι μια ρύθμιση ισχύος ήταν η πιο πιθανή αιτία.

Το διορθωμένο ιστορικό θα πρέπει να διατηρεί την πρώιμη διάγνωση, το μεταγενέστερο τεστ και το νέο συμπέρασμα. Θα πρέπει να δείξει γιατί άλλαξε το συμπέρασμα. Δεν πρέπει να επεξεργαστεί την πρώτη σημείωση για να φαίνεται σαν να γνώριζαν όλοι την απάντηση από την αρχή.

## Γιατί το νεότερο μοντέλο δεν είναι το επόμενο κεφάλαιο

Αλλάζουν και τα γλωσσικά μοντέλα. Ένα νέο μοντέλο δημιουργήθηκε από έναν διαφορετικό συνδυασμό πηγών, γλωσσών, ετικετών, ανθρώπινης ανατροφοδότησης και κανόνων προϊόντος. Μπορεί να έχει καλύτερη συνολική απόδοση, ενώ χάνεται μια παλαιότερη πολιτιστική αναφορά, τοπική πρακτική, αστείο ή μειονοτική ερμηνεία.

Η νέα απάντηση δεν είναι μια πλήρης ενημέρωση των γνώσεων του παλιού μοντέλου. Είναι μια νέα απάντηση από διαφορετικό μοντέλο.

Κάθε εύρημα καταγράφει ποιο μοντέλο το παρήγαγε, τι εμφανίστηκε στο μοντέλο και πότε απάντησε. Μια νεότερη απάντηση μπορεί να προστεθεί χωρίς να αντικατασταθεί σιωπηλά η προηγούμενη.

## Αφήστε ειλικρινή κενά

Μερικές φορές το αρχείο δείχνει ότι κάτι άλλαξε αλλά όχι γιατί. Σε αυτή την περίπτωση, ο λόγος παραμένει ανοιχτός.

Ένα ορατό κενό είναι πιο χρήσιμο από μια σίγουρη ιστορία που επινοήθηκε για να κάνει το χρονοδιάγραμμα να φαίνεται ολοκληρωμένο.
