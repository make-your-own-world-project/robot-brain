# 是什么帮助塑造了这项工作

![公共课程会带来价值，而做出贡献的人和作品仍然会得到认可。](../../illustrations/publish-reciprocity-open-paths.png)

本页面向塑造这项工作的人员、研究、公共项目、档案馆和社区表示感谢。主要的解释并不依赖于了解这些名称。他们来到这里是因为影响力应该保持可见。

商业语言模型无法命名每个形成答案的人或作品。这个项目可以更具体地讲述它自己的历史。

## 信用是如何记录的

一个条目说明了该作品的作者、作品名称、在哪里可以找到它以及它如何影响项目。它还将直接使用与测试、比较、拒绝或一般影响区分开来。当实际使用受保护的软件或材料时，也会记录适用的许可证。

这些差异很重要。阅读论文与包含其文本不同。测试公共程序与采用其设计不同。即使没有任何内容被复制，研究一种方法仍然可以影响以后的选择。

就像音乐家命名影响新音乐的艺术家一样，这份列表解释了是什么帮助塑造了作品。它并没有声称所有的影响都被纳入其中。分开的[来源、许可和隐私审查](../../SOURCES-LICENSES-AND-PRIVACY.md)涵盖程序、经过训练的文件以及实际使用或测试的其他材料。

信用并不意味着认可、参与或合作。此处列出的个人和组织仅对自己的工作负责。

## 详细信用清单

下面的一些 GitHub 项目根据其公开条款进行了有限的分析。其他的则被研究、比较或拒绝。它们都不能作为新的通用语言模型的培训材料。

## 文化作品、语言收藏、档案和社区

用于研究写作如何组织的主要收藏由记录为公共领域的作品组成。单独审查了一小部分明确发布供公众使用的公共标准。这是分析，而不是新的通用语言模型的训练。

私人来源记录标识了作品、其公共来源、测量合法的原因以及所检查的部分。由此产生的研究记录不保留文字的副本。它保留观察结果、用于确认检查了哪些材料的简短数字指纹以及返回公共来源的指示。

已确认的来源是：

- 古腾堡计划的公共领域书籍，包括儿童故事、民间故事、短篇小说、信件、日记、家庭指南和其他历史著作；
- 公共领域演讲和美国政府工作；
- 国会图书馆收藏的历史报纸页面，筛选其材料以了解已知的版权限制；
- 与 LibriVox 记录相关的公共领域书籍；未下载或分析任何音频；和
- 一小群互联网标准，其声明允许无限制分发或自由复制。

一项大型古腾堡计划索引发布于CC BY 4.0检查只是为了了解其中包含的内容。其书籍文件未被下载或测量。

古腾堡计划、其创始人迈克尔·S·哈特 (Michael S. Hart)、分布式校对者、参与的作者、编辑、译者和志愿者使这项工作的大部分内容成为可能。 LibriVox 志愿者和维护者也值得赞扬。国会图书馆、国家人文基金会报纸项目、互联网标准的作者和出版商以及保存原作的人们也是如此。

其他收藏和社区出现在更广泛的研究历史中。其中包括 Brown 语料库、Reuters-21578、NPS 聊天语料库、世界人权宣言翻译、arXiv、PubMed/MEDLINE、Delpher、维基百科、Stack Overflow、Hacker News 和 Mastodon。他们提供想法、问题、可能的比较或单独的研究材料。它们不是上述确认的公共领域集合。没有任何材料被描述为用于训练新模型的材料。他们的文本、帖子和收藏文件不包含在此处。

此处列出的作品和工具保留其自己的权利和条款。该文档记录了每种方法的可行性、不足之处以及是否已被使用、测试或仅被研究。

外部语言模型返回的工作被标识为模型生成的工作。已发表的研究保留其作者身份。发送一项任务的选定材料不会将该人的完整保存历史记录转变为项目资产或删除其中代表的任何人的权利。
