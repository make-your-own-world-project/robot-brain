# 記録を残してください。モデルを交換してください。

![個人の記録は 1 か所に残りますが、個別の作業部分が限られた仕事を処理します。](../../illustrations/specialist-assembly-line-vs-giant-chatbot.png)

Robot Brain は、人間の長期にわたる仕事の歴史と意味を保存するためのソフトウェアです。これは、言語モデル、チャットボット、またはすべての質問をモデルに転送するサービスではありません。

大規模な言語モデルは、調査、記述、説明し、困難な問題の解決に役立ちます。それらを中心に構築された有料サービスは、まだ一時的なワークスペースです。彼らは長い会話を短くし、以前の指示を失い、証拠から結論を切り離し、失われた歴史がまだ存在しているかのように書き続けることができます。その後、ユーザーは、すでに提供されているコンテキストを再構築するために、より多くの時間を費やし、有料の使用量を費やします。

このソフトウェアは、永続的な価値がどこに存在するかを変更します。その人の会話、文書、決定、失敗した試み、修正、未回答の質問は、その人が管理する記録に残ります。ローカル プログラムはそれらのレコードを検査できます。言語モデルは選択したジョブに役立ちますが、その貢献は古い、レビュー可能な作業として記録に戻ります。その後、履歴を残さずにモデルを置き換えることができます。

## 一つの見方でわかる違い

| 商用言語モデル サービス | Robot Brain |
|---|---|
| 現在作業ビューにあるマテリアルから回答を生成します。 | 完全なソースとそれに関連する履歴を保持します。 |
| 仕事が増えるにつれて、以前の会話が短くなったり、なくなったりする可能性があります。 | 会話をすべてのモデルの外部に保存して、再度使用できるようにします。 |
| それぞれの情報源とその状況に戻る完全な経路を持たずに、多くの情報源から学んだ知識を融合します。 | 既知の情報源をそれぞれ、後で発見、修正、不一致を個別の記録として保持します。 |
| 1 回のやり取りで独自の回答を作成、検索、計画、判断できます。 | 限られた権限で保存、検索、分析、書き込み、チェック、承認を個別の部分に与えます。 |
| モデル、サービス ルール、使用制限、製品の変更を制御します。 | 永続的な記録をその人の管理下に残します。 |
| 失敗した試行や修正交換、有用な作業に対して報酬が支払われます。 | レッスンを再度購入する必要がないように、失敗と修正を保存します。 |

Robot Brain ローカルまたはオンラインの言語モデルを呼び出すことができます。これはモデル プロキシにはなりません。元の会話に参加したモデルを呼び出すことなく、以前の作業を保存、検索、比較、整理、再構築できます。モデルが役立つ場合、リクエストは、そのモデルとは独立して存在するより大きなプロセスの 1 ステップです。

## なぜこれが建てられたのか

開発中に利用可能な最強の有料汎用モデルは、有能ではありましたが、長時間の作業を管理する信頼性の低いものでした。

記録された失敗には、指示の紛失、証拠の欠落、接続の発明、完了の時期尚早の主張、不要な変更、作業ファイルの損傷などが含まれます。それらの失敗を修正するには、より多くのリクエスト、より多くのテスト、より多くの有給手当、そしてより多くの時間とエネルギーが必要でした。このサービスは、使用できない作業に費やされた使用量や、修理に必要な交換品を自動的に返金するものではありませんでした。

問題は、どんな間違った答えよりも大きかった。一時的なテキスト ジェネレーターには、記憶、歴史家、研究者、作家、チェッカー、そして最終審査員としての役割が求められていました。モデルを変更してもその配置は変わりませんでした。

Robot Brain は異なる取り決めに基づいて構築されました。まず人間の記録を保持し、いくつかの交換可能なパーツをそれに貢献させ、重要な研究が受け入れられる前に生成モデルの外部に証拠を要求します。

## トレーニングされたモデルが保持できないもの

大規模な言語モデルは、人間の作業の膨大なコレクションからパターンを学習します。これらのパターンはモデルを有用なものにしますが、モデルはそれを形作った完全な作品のライブラリではありません。

モデル内では、書籍、記事、会話、翻訳、コミュニティ、ラベル、人間のフィードバックからの影響が融合されています。モデルは通常、どの情報源が特定の文を形成したかを示すことができません。すべての著者の目的、対象読者、証拠、意見の相違、後の修正、または失われた視点を復元することはできません。

それは、たとえオリジナルの作品がまだ他の場所に存在していたとしても、意味を失うことになります。モデルは、人間の設定に戻る信頼できる経路を破棄しながら、作品からの有用性をいくらか保持しています。

通常の使用でも同様の問題が発生します。最終的な答えは、それに意味を与えた会話が短縮された後でも生き残る可能性があります。結論は残りますが、失敗した試み、不確実性、およびその背後にある理由はモデルの作業ビューから消えます。

このプロジェクトは、人の人生について別のモデルをトレーニングすることでその問題に答えるものではありません。個人履歴は、別のトレーニング済みモデルにブレンドされるのではなく、読み取り可能かつ追跡可能なままになります。モデルは選択されたレコードを操作します。それらは記録にはなりません。

## それぞれの部分が何をするのか

この実用的なソフトウェアは、チャット サービスが 1 つのアクティビティのように見せるジョブを分離します。

一. **ソースキーパーは何が起こったかを保存します。** 会話、文書、画像、またはその他の資料を要約に置き換えずに保持します。
二. **検索可能なコピーにより、ソースの検索が容易になります。** コピーされたテキスト、説明、索引は、変更されていないソースを指し、再構築できます。
三. **焦点を当てた地元の読者が特定の特徴を調査します。** 別々の方法で、言語、発言、関係、推論、時間、人間の経験、価値観を調査します。それぞれが独自の発見とその背後にある一節だけを報告します。
四. **履歴レコードにより、変更が常に表示されます。** 新しい発見、修正、意見の相違、失敗した試行、および未解決の質問は、以前のイベントを書き換えることなく追加されます。
五. **リクエスト ビルダーは、1 つのジョブに必要なものを収集します。** 関連するソースと調査結果を選択し、何が含まれているか、何が省略されているかを記録します。
六. **言語モデルは限定的なヘルプを追加する場合があります。** ローカル モデルは幅広い背景を提供できます。オンライン モデルは、難しい調査や執筆を支援します。どちらの応答も日付が記載された投稿として残り、チェック、拒否、または置き換えることができます。
七. **個別のチェックにより、結果がリクエストおよび証拠と比較されます。** 回答を作成したモデルは、自身の作業が受け入れられたと宣言できません。
八. **画面を使用してソフトウェアを使用できます。** 付属のLibreChatfork もそのような画面の 1 つです。交換しても、レコードやその他の動作部品は交換されません。

単一の部分が全知のアシスタントとして表示されることはありません。彼らの仕事は限られているため、各部品は交換可能です。

## 完了した会話を再び役立つものにする

完了した会話には、ユーザーの要求、言語モデルの実際の応答、試みた作業、失敗、修正、および交換が終了した時点が含まれます。これらのメッセージは、後でそのモデル自体を説明する必要なく、元のモデルが貢献したものを保持します。

地元の読者が、保存されたやり取りをさまざまな角度から調査します。彼らは、広い世界の知識に頼ることなく、詳細なパターンや関係を見つけることができます。彼らの別々の調査結果は、依然として会話の正確な部分と関連しています。

これらの発見は、明確な説明を形成する前に、依然として一般的な背景知識を必要とする可能性があります。その限られた一歩のために、小さなQwenモデルはローカルで実行されますvLLM。詳細な調査結果を結び付け、交換が何を達成したかを説明するのに役立つ日付の概要が追加されます。

Qwenオンライン モデルの隠された思考やトレーニング履歴は復元されません。オリジナルのモデルに固有ではない幅広い背景知識を提供します。元のモデルの有用な貢献は、それが生成した言葉の中にすでに保存されています。

のQwen概要はソースと以前の調査結果の横に保存されます。修正または交換できます。元の会話と詳細な現地分析は変更されません。

## 今何が機能しているのか

現在の実装では、完了した会話を保存し、個別のローカル メソッドでそれを検査し、ローカルの一般知識の読み取りを追加し、保持されたすべての貢献を後で再構築できるレコードに収集できます。

外部からの支援が役立つ場合には、オンライン モデルに対する限定的なリクエストを準備することもできます。そのサービスは、選択された素材のみを受け取ります。その答えはローカル記録に戻ります。そこでは、モデルではなく、チェックと人間の承認によって、何を保持するかが決定されます。

これが中心的な成果です。かつて 1 つの一時的な会話に依存していた作業は、チャット画面、モデル、プロバイダーがなくなった後も有用であり続けることができます。
