# Construya el documento antes de escribir la prosa.

![Un documento se planifica, redacta, verifica y acepta en pasos separados.](../../illustrations/artifact-assembly-line.png)

Darle a un modelo de lenguaje una solicitud y una pila de archivos a menudo produce un documento que suena terminado antes de estar sólido. Es posible que falten pruebas importantes. El mismo punto puede aparecer en varias secciones. El relleno suave puede ocultar la única frase que el lector necesitaba.

Robot Brain planifica el resultado antes de pedirle a un modelo de lenguaje u otro método de escritura que lo redacte.

## Comience con el lector y el propósito.

Una guía de mantenimiento, una explicación pública, un resumen de investigación y una historia personal son trabajos diferentes. Antes de recoger el material, la solicitud identifica:

- ¿Quién leerá el documento?
- lo que necesitan de ello
- qué preguntas debe responder
- qué evidencia se requiere
- ¿Cuánto detalle es razonable?

## Encuentre la evidencia que cada sección necesita

El plan funciona al revés a partir de esas preguntas. Busca los eventos, reclamos, decisiones, intentos fallidos, correcciones y preguntas abiertas necesarias para responderlos.

Cada hallazgo apunta a su fuente. Si los lectores disponibles no pueden respaldar una respuesta, el plan deja la pregunta abierta.

## Haga un plan para todo el documento

Intentos anteriores recuperaron pasajes con redacción similar y trataron la pila como una explicación. Otros intentos pidieron a un modelo de lenguaje que escribiera secciones por separado. El resultado se repitió, cambió términos entre secciones e inventó conexiones que no estaban en la evidencia.

Un plan de documento completo hace visibles esos problemas antes de escribir la prosa. También decide qué se puede omitir sin revelar la historia.

## Escribe sólo lo que la evidencia pueda contener.

La etapa de escritura ordena el material, explica términos desconocidos y conecta las secciones para el lector previsto.

Un modelo de lenguaje puede ayudar con la redacción. No puede agregar un hecho, motivo o nivel de certeza que las fuentes no respalden. Un borrador más fluido no es una mejora si se vuelve menos preciso o tarda más en leerse.

## Consulta el documento completo

La revisión final pregunta si el documento responde a las preguntas requeridas, utiliza sus fuentes con honestidad, mantiene visibles incertidumbres importantes y se adapta al tiempo disponible del lector.

Lo que se acepta es el documento terminado exacto que pasó esos controles. No basta con una colección de párrafos individualmente exitosos.
