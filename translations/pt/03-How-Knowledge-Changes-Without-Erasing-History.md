# Mantenha a correção sem apagar o erro

![Evidências anteriores, compreensão posterior e mudanças permanecem conectadas ao longo do tempo.](../../illustrations/temporal-meaning-preserved-history.png)

Compreender as mudanças. Novas evidências podem corrigir uma conclusão anterior. Um teste posterior pode mostrar que a primeira explicação estava errada. Isso não torna o registro anterior inútil.

O erro pode explicar por que foi tomada uma decisão, por que se perdeu tempo ou por que existe agora uma salvaguarda. Reescrever a nota antiga esconderia essa história.

## Um evento pode ter várias datas

A data em um arquivo nem sempre é a data do evento dentro dele. Um registro útil pode precisar distinguir:

- quando algo aconteceu
- quando alguém escreveu
- quando o arquivo foi salvo aqui
- quando uma interpretação posterior foi feita
- quando uma conclusão se tornou atual ou foi substituída

Se uma dessas datas não for conhecida, ela permanece desconhecida.

## Um exemplo simples

Uma nota inicial culpa uma peça quebrada. Um teste posterior mostra que uma configuração de energia foi a causa mais provável.

A história corrigida deve manter o diagnóstico precoce, o exame posterior e a nova conclusão. Deve mostrar por que a conclusão mudou. Não se deve editar a primeira nota para parecer que todos sabem a resposta desde o início.

## Por que o modelo mais novo não é o próximo capítulo

Os modelos de linguagem também mudam. Um novo modelo foi construído a partir de uma combinação diferente de fontes, idiomas, rótulos, feedback humano e regras de produto. Pode ter um desempenho geral melhor, ao mesmo tempo que perde uma referência cultural mais antiga, uma prática local, uma piada ou uma interpretação minoritária.

A nova resposta não é uma atualização completa do conhecimento do modelo antigo. É uma nova resposta de um modelo diferente.

Cada descoberta registra qual modelo a produziu, o que o modelo foi mostrado e quando respondeu. Uma resposta mais recente pode ser adicionada sem substituir silenciosamente a anterior.

## Deixe lacunas honestas

Às vezes, o registro mostra que algo mudou, mas não por quê. Nesse caso, o motivo permanece em aberto.

Uma lacuna visível é mais útil do que uma história confiante inventada para fazer a linha do tempo parecer completa.
