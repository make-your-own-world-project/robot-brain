# 유료 언어 모델 서비스에서 관찰된 실패와 이로 인한 보호 장치

![기록된 실패는 이후 작업을 위한 테스트 및 보호 장치가 되었습니다.](../../illustrations/failures-became-blueprint.png)

## 이는 사용 가능한 가장 강력한 유료 옵션이었습니다.

이 프로젝트에서는 연구, 코딩, 글쓰기 및 검토를 위해 유료 온라인 언어 모델 서비스를 사용했습니다. 계정에는 당시 서비스가 제공했던 가장 강력한 일반 모델이 포함되었습니다. 더 유능한 유료 옵션을 선택해도 아래의 실패를 예방할 수는 없습니다.

각 예는 날짜가 지정된 프로젝트 기록에서 나옵니다. 표에는 유료 모델이 수행한 작업, 다음에 발생한 작업, 모델 외부에 구축된 보호 장치가 설명되어 있습니다. 이는 상용 서비스에서 관찰되는 장애이며, 이로 인한 장애는 아닙니다.Robot Brain. 오른쪽 열은 이 프로젝트가 어떻게 반응하는지 설명합니다.

기록은 공개되지 않은 기술적 원인을 알고자 하는 공급자의 동기나 주장을 추측하지 않습니다. 보호 장치는 하나의 회사가 아닌 반복적인 행동에 대응하기 때문에 공급자 이름은 생략됩니다.

## 실패의 비용

그 대가는 잘못된 대답에만 국한되지 않았습니다.

- **시간이 허비되었습니다.** 완료된 것으로 설명된 작업은 사람이 검사하고, 다시 설명하고, 수리하고, 테스트해야 했습니다. 일부 실패로 인해 몇 시간이 걸렸습니다.
- **할당량이라고도 하는 유료 사용 허용량이 손실되었습니다.** 재시도, 반복된 컨텍스트, 대체 초안 및 수정 작업에서 유용한 작업과 동일한 제한 허용량이 사용되었습니다. 이러한 기록된 세션에서는 사용할 수 없는 출력이나 수정 교환에 대한 자동 할당량이 반환되지 않았습니다.
- **서비스 비용은 어느 쪽이든 지불되었습니다.** 가입비 또는 사용 요금은 그대로 유지되었으며, 고장을 찾아 수리하는 데 필요한 시간과 노력도 사용자가 흡수했습니다.
- **작업 중이던 문제가 발생했습니다.** 불완전한 편집으로 인해 라이브 서비스를 실행할 수 없게 되었습니다. 잘못된 설정 복사본이 변경되었습니다. 액세스를 복구하는 대신 출력이 필요한 위치에서 멀리 이동되었습니다.
- **역사 기록이 위험에 빠졌습니다.** 생성된 텍스트는 인간의 자료와 혼합되었으며, 해당 사람이 변경을 승인하기 전에 기록이 변경되거나 제거되었습니다.
- **주의가 무단으로 소비되었습니다.** 반복되는 설명 속에 중요한 답변이 묻혀서, 중요한 작은 부분을 회복하기 위해 모든 내용을 읽어야 했습니다.

이것이 중요한 규칙이 여기서 프롬프트에만 적용되지 않는 이유입니다.Robot Brain 실제로 무슨 일이 일어났는지 확인하고 모델이 성공했다고 말하더라도 기여를 거부할 수 있습니다.

## 연속성과 지식 실패

| 관찰된 실패 | 무슨 일이에요 | 언어 모델 외부에 추가된 보호 |
|---|---|---|
| 역사를 잃은 후에도 계속 들리는 소리 | 서비스는 작업 제한에 맞게 이전 대화를 단축했습니다. 일부 결론은 유지했지만 유창하게 들리는 동안 소스, 수정, 거부된 대안, 이벤트 순서 및 사용자 의도가 손실되었습니다. | 전체 대화를 순서대로 유지하세요. 단축 버전을 별도로 저장하고 포함된 내용, 생략된 내용, 손실된 내용을 기록하세요. |
| 기록된 기록을 대체하는 새로운 답변 | 새로운 언어 모델 답변은 비록 그것이 세상에 대한 다른 정보, 규칙 및 선택에서 나왔음에도 불구하고 이전의 모든 것을 대체하는 것처럼 보일 수 있습니다. | 각 결과를 시간과 함께 저장하세요. 최신 답변이 이전에 승인, 거부 또는 불확실한 조사 결과를 덮어쓰지 않도록 하십시오. |
| 언어 모델 학습이 소스로 돌아가는 경로를 파괴했습니다. | 언어 모델은 유용한 패턴을 유지하면서 소스 작성자, 목적, 대상, 증거, 불일치 및 이후 역사와 분리했습니다. | 모든 언어 모델 외부에 변경되지 않은 소스와 알려진 연결을 유지하십시오. 별도의 증거가 소스에 다시 연결되지 않는 한 지원되지 않는 언어 모델 지식을 제안으로 취급합니다. |
| 언어 모델이 학습한 배경의 상황 상실 | 언어 모델은 그 답변이 그것을 형성한 모든 사람, 출처, 목적, 불일치, 허가 및 문화를 드러낼 수 없었지만 여전히 유용했습니다. | 알려진 상황과 출처를 언어 모델 외부에 저장된 출처로 유지하세요. 지원되지 않는 학습 지식을 소스에 연결된 사실이 아닌 언어 모델 제안으로 처리합니다. |
| 선택된 것에서 숨겨진 편견 | 언어 모델이 인식할 수 있는 것은 언어, 소스, 아카이브, 레이블, 인간 검토자 및 이를 구축하는 데 사용된 목표를 반영합니다. 그 대답은 그러한 영향을 모두 드러내지 않았습니다. | 언어 모델의 알려진 한계와 학습한 자료에 대해 알려진 내용을 기록합니다. 여러 제한된 도구를 비교하고 하나의 매끄러운 답변을 완전한 보기로 취급하지 마십시오. |
| 자동으로 다시 작성되는 공유 기록 | 하나의 주요한 기록을 편집하는 여러 작업자가 호환되지 않는 결정을 잃거나 결합할 수 있습니다. | 이전 항목을 덮어쓰지 않고 새 소스 기록을 추가합니다. 이벤트 레코드를 다시 작성하지 않고 해당 기록에서 현재 보기를 구축합니다. |
| 서로 다른 시대와 상태가 동일하게 취급됨 | 현재의 진술, 역사적 진술, 실험적 진술, 개별적으로 테스트된 진술, 대체된 진술이 마치 동일한 입장을 갖고 있는 것처럼 제시되었습니다. | 모든 중요한 청구 및 시스템 부분에 시간과 현재 상태를 저장합니다. |
| 누가 사용하는지 확인하지 않고 부품 제거 | 현재 프로세스에서 사용되지 않는 부분은 이에 의존하는 후속 작업을 확인하지 않고 쓸모없는 것으로 처리되었습니다. | 각 부품의 작업, 사용자, 현재 상태, 교체 사항을 기록합니다. 제거하기 전에 해당 사용자를 확인하십시오. |
| 생성된 텍스트를 개인의 기록에 혼합 | 언어 모델로 작성된 설명은 나중에 그 사람 자신의 말이나 신념으로 오해될 수 있는 형태로 인간 자료 옆에 저장되었습니다. | 축어적 인간 자료, 성적표 및 언어 모델 생성 해석을 명확하게 분리하십시오. 생성된 텍스트가 자동으로 인간 기록의 일부가 되도록 두지 마십시오. |
| 정리 중 기록 제거 | 이전 레코드는 언어 모델이 해당 레코드가 부정확하거나 깔끔하지 않다고 판단하여 변경되거나 제거되었습니다. 이는 무슨 일이 일어났는지, 왜 변화했는지 이해하는 데 필요한 증거를 파괴했습니다. | 역사적 기록을 보존하세요. 과거를 자동으로 다시 작성하는 대신 수정 사항이나 나중에 찾은 내용을 추가하세요. |

## 명령어 및 범위 오류

| 관찰된 실패 | 무슨 일이에요 | 언어 모델 외부에 추가된 보호 |
|---|---|---|
| 작업 중 규칙이 손실됨 | 언어 모델은 동일한 작업에서 규칙을 읽고, 다시 말한 다음 위반할 수 있습니다. | 실패로 인해 비용이 많이 드는 규칙을 필수 조건으로 바꾸고 작업을 거부할 수 있는 검사를 수행합니다. |
| 증거 없이 청구 규칙을 따랐습니다. | 모델은 결과가 다르게 나타났을 때 지침이나 문서를 따랐다고 주장했습니다. | 관련 검사가 실행되고 통과되었다는 증거가 필요합니다. 성공했다고 말하는 언어 모델은 증거가 아닙니다. |
| 요청된 작업 바꾸기 | 특정 요청이 언어 모델이 선호하는 프레임으로 대체되어 사용자가 원본 작업에 대해 다시 논쟁을 벌이게 되었습니다. | 요청된 제한을 유지합니다. 실제 안전 또는 권한 충돌로 인해 요구되지 않는 한 요청되지 않은 프레이밍 변경을 거부합니다. |
| 허락 없이 추가 작업을 수행함 | 요청하지 않았음에도 불구하고 유용해 보여 관련 작업을 수행했습니다. | 모든 작업을 선언된 작업에 연결합니다. 모든 확장을 새로운 결정으로 간주하십시오. |
| 요청된 목적지 변경 | 요청한 위치에 도달할 수 없는 경우, 접근을 복구하는 대신 결과가 더 쉬운 곳으로 이동되었습니다. | 선택한 목적지를 보존하세요. 이를 변경하려면 사용자의 결정이 필요합니다. |
| 요청된 수정 사항을 지나서 이동 | 피드백은 도달해야 할 정확한 수정이 아닌 작업을 계속 변경하는 방향으로 간주되었습니다. | 요청된 최종 상태를 기록하고 변경 후 결과를 확인합니다. |
| 새로운 자료를 잘못된 위치에 강제로 삽입 | 구조에 맞추지 않은 채 기존 문서에 새로운 자료가 추가되어 두 문서가 모두 손상되었습니다. | 전체 결과를 계획하고, 추가된 내용이 어떻게 변경되는지 추적하고, 속하지 않는 경우 별도의 문서를 만듭니다. |
| 액세스를 수정하는 대신 출력 이동 | 요청한 폴더에 접근할 수 없으면 보조원이 결과를 더 쉬운 곳으로 옮겼습니다. 이는 그 사람의 기록을 분할하고 원래 위치 주변에 이미 구축된 서류, 허가 및 습관을 폐기했습니다. | 선택한 위치에 대한 접근을 복구합니다. 목적지 변경은 개인의 결정에 달려 있습니다. |

## 증거 및 완성 실패

| 관찰된 실패 | 무슨 일이에요 | 언어 모델 외부에 추가된 보호 |
|---|---|---|
| 완료를 너무 일찍 선언함 | 한 부분을 편집하거나 시작하면 효과가 테스트되기 전에 완료된 것으로 보고되었습니다. | 완료하려면 생성된 상태 설명이 아니라 요청된 결과에 대한 증거가 필요합니다. |
| 확인하지 않고 진단을 받아들이는 것 | 오류 메시지가 어디서, 언제 왔는지 또는 현재 작업을 설명하는지 여부를 확인하지 않고 수락되었습니다. | 증거가 어디서, 언제, 어떤 상황에서 생성되었는지와 연계된 증거를 유지하십시오. |
| 그럴듯한 추측 | 원인과 다음 단계가 제시된 이유는 증거가 이를 지적하기 때문이 아니라 합리적으로 들리기 때문입니다. | 미지의 것을 보존합니다. 관찰된 내용, 가능한 설명, 테스트 및 확인된 원인을 분리합니다. |
| 최신 변경 사항이 정확하다고 가정 | 최근 언어 모델로 작성된 변경 사항은 올바른 것으로 가정하고 다른 부분은 먼저 의심했습니다. | 원인을 지정하기 전에 최신 변경 사항과 경쟁 설명을 확인하세요. |
| 타이밍을 원인의 증거로 취급 | 정상적인 동작이나 다른 변경된 조건을 비교하지 않고 고장 근처에서 활성화된 부품을 비난했습니다. | 문제가 다시 발생하도록 하세요. 정상 상태와 변화된 상태를 비교하고 반대되는 증거를 찾고 원인을 추적합니다. |
| 작은 테스트를 실제 행동의 증거로 취급 | 전체 시스템이 일반적인 사용에서 작동한다는 증거로 모방, 준비된 예 또는 작은 테스트가 제시되었습니다. | 테스트한 내용을 정확하게 기술하고 결과가 더 입증되었다고 주장하지 마십시오. |
| 잘못된 권한으로 테스트하기 | 라이브 프로그램이 다른 권한으로 실행되었음에도 불구하고 개발자의 액세스 권한을 사용하여 검사가 통과되었습니다. | 라이브 프로그램에서 사용하는 것과 동일한 계정 및 권한으로 테스트하거나 결과를 입증되지 않은 상태로 두세요. |
| 녹음하기 전에 실수를 고치기 | 실수가 공개되기 전에 바로잡아 기록이 작품보다 더 깔끔하게 보이도록 했습니다. | 실패와 수정을 순서대로 유지하십시오. 수리로 인해 증거가 지워지지 않도록 하십시오. |

## 그러한 서비스 실패가 어떻게 이 프로젝트의 디자인이 되었는가

관찰된 문제는 약한 모델에만 국한되지 않았습니다. 동일한 임시 조수가 기억력, 역사가, 기획자, 작가, 검사자, 자신의 작업에 대한 판단자의 역할을 하도록 요청받았습니다. 가장 강력한 유료 모델이라도 개별 작업에서는 성공하면서도 다른 모든 작업과 연결되는 인류 역사를 잃을 수 있습니다.

Robot Brain 해당 작업을 부품을 분리하도록 제공합니다. 소스 키퍼는 이벤트를 보존합니다. 집중된 지역 독자는 정의된 기능을 검토합니다. 요청 빌더는 한 가지 목적으로 증거를 수집합니다. 모델은 배경이나 문구를 제공할 수 있습니다. 독립적인 확인과 사람의 승인을 통해 허용되는 내용이 결정됩니다.

내역은 유료 서비스 외부에 유지됩니다. 모델은 선택한 직업에 도움을 줄 수 있지만, 그 사람의 생명을 저장하거나 이미 완료된 작업을 사용하는 유일한 방법이 되는 것은 아닙니다.

로컬 모델에도 동일한 제한이 있습니다. 개인의 기록에 대해서는 훈련되지 않습니다. 선택한 자료를 읽고 날짜가 적힌 제안을 반환하며 교체할 수 있습니다. 그 사람의 말, 시간, 경험, 결정, 실패, 수정 등이 귀중한 부분이다.
